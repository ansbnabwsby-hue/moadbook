# موقع moadbook المتوافق مع Android 1.10.5

هذا مجلد موقع moadbook العربي/PWA المنشور على GitHub Pages. أُعيد استخدام مصدر PWA المقروء السابق، وهو أقرب مصدر كامل إلى واجهة Android 1.10.5؛ أما مصدر Expo/React Native الأصلي فيبقى منفصلًا في `../moadbook-web/`.

## الميزات الموجودة في واجهة الويب

تتضمن الواجهة تسجيل الحساب والدخول والملف الشخصي، موجز المنشورات والبحث والتصفية، أنواع المنشورات وحالات المزاج واختيار الخط، سؤال اليوم، الاستطلاعات والتصويت، اختيار صورة واحدة وضغطها/تحريرها، روابط الوسائط، الإعجاب والتعليقات والحفظ، مشاركة المنشور كصورة أو نص، الأعضاء وطلبات الصداقة والمتابعة، دليل المجتمعات وتصنيفاتها وإنشاءها والانضمام، الرسائل ومرفقات الصور ومؤشر الكتابة، الإشعارات داخل التطبيق، أدوات الإخفاء والحظر والإبلاغ، إعدادات المظهر وإمكانية الوصول، والملاءمة للتثبيت كتطبيق PWA.

## التثبيت على iPhone

افتح <https://ansbnabwsby-hue.github.io/moadbook/> في Safari، ثم اضغط **مشاركة → إضافة إلى الشاشة الرئيسية**. لا يدعم Safari تثبيت PWA بزر تثبيت عام من داخل الموقع؛ لذلك تظهر للمستخدم تعليمات المشاركة. استخدم هذا الخيار على جهازك الشخصي فقط ولا تشارك الهاتف مع بقاء الجلسة مفتوحة.

يحفظ Service Worker واجهة التطبيق وأصولها فقط لفتح shell عند ضعف الاتصال؛ عمليات Firebase والرسائل والنشر تحتاج إنترنت. لا تُخزّن بيانات القاعدة داخل كاش Service Worker. يوجد مستمع Web Push في الشيفرة، لكن الإشعارات الفعلية عند إغلاق الموقع غير مفعّلة حتى إعداد VAPID وخدمة إرسال خلفية موثوقة وتسجيل الاشتراكات بإذن المستخدم ومراجعة قواعد Firebase.

## Firebase وعدم تغيير الإنتاج

تستعمل الواجهة إعداد العميل نفسه ومسارات قاعدة Firebase الحالية في تطبيق moadbook. إعداد Firebase الموجود في `firebase-config.js` إعداد عميل، وليس مفتاحًا إداريًا؛ قواعد RTDB الفعلية هي التي تحكم صلاحيات القراءة والكتابة. هذا المستودع لا ينشر أو يغيّر قواعد Firebase أو بياناتها. لا ترفع مفاتيح إدارة أو أسرار VAPID الخاصة أو بيانات مستخدمين إلى GitHub.

إعجابات التعليقات تستخدم المسار الجديد `/commentLikes/{postId}/{commentId}/{uid}` وتبقى غير متاحة حتى تضيف يدويًا قاعدة `commentLikes` الإضافية إلى قواعد RTDB الحالية. القاعدة تقصر القراءة على الحسابات المسجلة، وتسمح لكل حساب بإعجاب واحد قابل للإزالة تحت UID الخاص به، مع اشتراط وجود المنشور والتعليق وعدم الحظر المتبادل مع صاحب التعليق. لا تستبدل قواعد مشروعك كلها بملف آخر؛ أضف هذا الفرع مع المحافظة على بقية القواعد.

## الملفات

- `index.html`: بنية التطبيق ونقطة الدخول.
- `app.js` و`styles.css`: وظائف الواجهة وتنسيق RTL.
- `post-export.js`: تجهيز مشاركة بطاقة المنشور.
- `firebase-config.js`: إعداد Firebase العام المستخدم من العميل.
- `manifest.webmanifest` و`sw.js`: تثبيت PWA وكاش shell والتنبيه عند توافر خدمة إرسال.
- `fonts/` و`ASSET-LICENSES/`: الخطوط وأذوناتها.

لا يحتوي هذا المجلد على `database.rules.json` أو ملفات Cloud Functions، تجنبًا لتطبيق تغييرات خلفية أو قواعد إنتاجية من غير موافقة واختبار منفصل.

## حدود التكافؤ

تغطي هذه الدفعة واجهات وسلوكيات Android 1.10.5 الموجودة في مصدر PWA السابق. لا تنشئ المجتمعات الحالية صفحات نقاش خاصة أو أدوارًا/طلبات عضوية متقدمة. كما أن معاينة بعض منصات الفيديو ورفع صور المنشورات لم يتغيرا عن Android 1.10.5، ولا ندعي إصلاحهما نهائيًا أو التحقق منهما على Firebase حي. قد ترفض قواعد Firebase الحالية بعض الحقول إذا لم تكن محدثة؛ لم تُنشر قواعد جديدة في هذه الدفعة.

## الفحوص

```bash
node --check app.js
node --check post-export.js
node --check sw.js
python3 -m json.tool manifest.webmanifest >/dev/null
```
