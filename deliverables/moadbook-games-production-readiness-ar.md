# تقرير جاهزية Moadbook Games للاختبار

**التاريخ:** 10 نوفمبر 2026
**الحالة:** النسخة الأساسية منشورة على GitHub Pages. تحسينات الواجهة وإصلاح Memory والصوت ولعبة XO اجتازت الفحوص وأُعدّت في فرع منفصل؛ لم تُدمج تحسينات الواجهة في `main` ولم تُنشر إلى Pages بعد. ترحيل Supabase وإصدار Edge Function الخاصان بـXO نُشرا بالفعل.

**رابط بوابة الألعاب:** <https://ansbnabwsby-hue.github.io/moadbook/games/>

## ما يتضمنه الإصدار المنشور

أُضيف قسم ألعاب مستقل داخل Moadbook مع بوابة RTL عربية وصفحات لعب مستقلة ومشغّل مشترك. تتضمن النسخة الأساسية Runner وMemory وQuiz وBlock Puzzle وSnake، مع الاكتشاف والترتيب والملف الشخصي ولوحة إدارة منفصلة للألعاب.

تستخدم الألعاب حساب Firebase الحالي. تتحقق Edge Function من Firebase ID token على الخادم، وتستدعي وظائف قاعدة البيانات بصلاحية خدمة محفوظة على الخادم فقط. بيانات الألعاب في مخطط `moadbook_games` المعزول، ولا تملك الواجهة صلاحية مباشرة لكتابة النقاط أو نتائج الترتيب. وظائف RPC محصورة بـ`service_role`. تحسب مكافأة Memory بوقت قاعدة البيانات بدل الاعتماد على مدة يرسلها العميل.

يحتوي بنك Quiz على **26 سؤالًا**: 20 سؤالًا في المعرفة والعلوم والتاريخ والجغرافيا والتقنية والثقافة، و6 مسائل رياضيات موثقة حسابيًا.

## تحسينات جاهزة على فرع التطوير

- إصلاح خطأ DOM الذي منع تركيب وحدة تحدي الذاكرة.
- إضافة مؤثرات Web Audio اختيارية وزر كتم/تشغيل يحفظ التفضيل محليًا.
- إضافة XO عربية ضد روبوت، مع احتساب النتيجة خادميًا وإعادة بناء نقلات اللاعب قبل قبولها.
- إضافة بحث وفلتر لقائمة الألعاب، مع إخفاء قسم الألعاب المميزة عند البحث لتوضيح النتائج.

تحقق API الحي من ظهور ست ألعاب ورفض بدء جولة بلا Firebase token. أعادت فحوص قاعدة البيانات نتائج 100 للفوز و50 للتعادل و10 للخسارة، ورفضت النقلات المكررة والجولات غير المكتملة؛ لا يملك `anon` صلاحية تنفيذ دوال XO أو إنهاء الجولات. اختبر Chromium محليًا ست بطاقات، ونتيجة بحث واحدة عن `snake`، وأربع ألعاب في فلتر المميزة. اجتازت ملفات JavaScript وTypeScript وSQL وHTML الفحوص المحلية.

## ما لم يُختبر بعد

لم يُجرَ اختبار جولة كاملة بتسجيل دخول Firebase حقيقي، ولم تُرسل نتيجة مستخدم تجريبية؛ لذا يلزم اختبار النقاط والترتيب يدويًا. كذلك، تبقى XO والصوت والبحث والفلتر غير ظاهرة على الموقع العام إلى أن يُدمج تحديث الواجهة ويكتمل نشر Pages.

## خطوات التجربة

افتح [بوابة الألعاب](https://ansbnabwsby-hue.github.io/moadbook/games/) من Chrome على Android وسجّل الدخول بحساب Moadbook. بعد نشر تحسينات الواجهة ستجد خيارات الصوت وXO والبحث في الكتالوج. أكمل جولة موثقة ثم افحص النتيجة في الملف أو لوحة الترتيب. إذا كانت نسخة PWA مثبتة قديمة، افتح الموقع في المتصفح وأعد تحميل الصفحة مرة واحدة لتحديث الملفات.

لم تُعدّل قواعد Firebase أو بيانات المستخدمين الاجتماعية. إضافة XO اقتصرت على مخطط الألعاب ودالة API الخاصة بها.
